# 贡献指南

## 适合提交的内容

- 改进 `SKILL.md` 的触发和工作流说明
- 改进模板边界、追踪关系和自检项
- 增加新的项目类型示例
- 改进 README、文档和多语言内容
- 修复辅助脚本、模板或示例与 skill 定位不一致的问题

## 提交前要求

- 不要破坏 `skills/spec-init/` 的核心结构
- 不要把不同宿主拆成多套独立 skill
- 更新模板时，同步检查示例项目是否仍然成立
- 文档和示例应保持一致
- 提交前至少运行一次 `bash tests/spec-init.sh`

## 建议流程

1. 先在 issue 中描述动机
2. 再提交 PR
3. PR 中明确说明影响范围和变更原因
