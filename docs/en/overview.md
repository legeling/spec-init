# spec-init Overview

spec-init maintains effective agreements with effort proportional to risk. Small fixes need no new documents, features update existing specs, and high-risk changes retain design and recovery verification.

The [project README](../../README.en.md) owns usage, scaffold behavior, and upgrade guidance. See the [skill](../../skills/spec-init/SKILL.md) for its workflow.
