# spec-init 精简方案与验收

日期：2026-09-05。范围：本 Skill 的规则、资源、骨架与验证；不迁移其他业务仓库，不提交或发布。

## 问题与目标

旧入口 445 行，两份必读参考共 297 行；中文基础模板 41 个文件，规则目录 12 个文件、657 行。生成的 AGENTS 将编码放在第 17 步，每次变更要求维护工作区与多个同步目标。新规则应缩小默认文档投入，同时维持有效约定和必要风险验证。

## 已定方案

- 按任务风险选择投入。小修复可以零文档变化，普通功能原位更新一份相关说明；高风险变化写清契约、失败恢复和验证，完整设计按用户明确范围展开。
- 一个主题保留一份权威需求文档；用户确认变化即替换原需求和验收，实施未完成标为待实施。计划只记动作和进度并引用权威需求；纠正相关现行文档中的旧说法，包括 AGENTS。
- 历史仅用于追溯，不提供当前指令。默认检索排除已知历史范围，发现冲突根据确认的意图、契约、代码与测试判断，不能只按日期或代码决定。
- 开工以目标、边界、验证和关键决策充分为准。取消强制编号链、五文件 change、全量文档收敛、七份测试文档及完成必须移动目录。
- 入口保持简短，复杂设计、迁移、示例按需读取；不生成通用工程规则大全。
- 骨架只生成 README、AGENTS、docs/README。沿用参数和双语支持，项目类型变为描述信息；不新增依赖。

## 实施与所有权

主 Agent 负责核心 Skill、脚本、模板、示例、测试、文档、兼容判断和最终交付。固定 luna_worker（gpt-5.6-luna / max）用于隔离场景试用，主 Agent 复核实际产物。完整实现批次和静态审查结束后才运行统一验证。

旧模板与示例中的重流程内容从本 Skill 包中移除，避免被再次安装或参考。README、元数据和贡献模板同步说明新行为，保留安装接口和许可证。

## 兼容、升级与回滚

- 安装器接口不变。脚手架不再输出旧的阶段树或类型专属文档，这是有意改变的输出契约。
- 默认不覆盖项目已有文件。骨架 --force 仅在项目外备份并替换三个目标文件，不删除旧目录；验证错误应在写入前失败，拒绝通过符号链接写出目标范围。
- Skill 安装器 --force 仍会替换整个安装目录，不能与骨架的 --force 混淆。更新本机副本前把原安装备份到技能发现目录之外，验证后比对包内容；不修改其他项目已生成的规则。
- 旧项目保持原路径，迁移时只改获准的旧门禁片段，保留项目专有约束；入口标明哪些内容生效。不能把保留旧文件误报成完成规则迁移。
- 回滚恢复备份或本批次差异，仅处理本次文件；后续编辑需要人工合并，不能盲目覆盖。

## 成本取舍

核心收益来自减少默认读取和多处写回，不承诺未经测量的 token 比例。骨架固定三个目标，时间和 I/O 随其文本大小线性增长，空间为单文件渲染与被替换文件的备份；备份仅在显式 --force 时产生。普通任务读取相关主题，不默认扫描随历史增长的整套文档。

## 验收标准

| 场景 | 可观察结果 |
|---|---|
| 新项目骨架 | 仅三个文件，无 rules、change、topology 或源码占位；双语与全部类型可用 |
| 现有项目 | 重跑保留原内容；force 备份可恢复，旧目录不变；无效参数、symlink 不越界写入 |
| 小 bug | 实际修复与验证，不为满足 Skill 新建文档或追踪编号 |
| 普通功能 | 实现后原位更新相关约定，不复制到多层文档 |
| 需求反转 | 更新原计划、撤下过期动作，历史方案不重新进入实现 |
| 高风险迁移 | 先明确数据兼容、部分失败、幂等或恢复验证，不因精简而省略风险决策 |

脚本与静态检查证明包和文件行为；隔离场景试用检查模型决策。有限场景不能证明所有宿主或长期真实项目的表现。

## 唯一真源修正

首轮把新需求先放计划、等实现完成再更新功能文档，仍可能让旧需求在当前文档中生效。现改为确认即原位更新权威需求和验收，实施状态另记；其他现行文档的冲突必须纠正或改为引用。AGENTS 仅保留四条提示，业务事实放权威文档。既有项目的特有安全、数据和发布约束仍需保留。

本轮专项首试确认旧需求得到替换且代码未动，但仍有新需求复述到多个现行文件、无关运行说明丢失的问题。已将对应规则改为“需求和验收副本改链接，保留无关内容”，并重试同一隔离样例；这不等于所有业务仓库已迁移。

专项重试复核通过：权威文档原位替换需求与验收并标为待实施，README/AGENTS 改为引用，设计仅记实现差距，计划仅记动作；代码、原运行命令和生产限制均保留，未新建并行需求。44 项脚本行为检查、Skill 校验及本地链接检查通过；末次仅调整措辞，未重复运行不受影响的脚本检查。本机副本已同步并保留更新前备份；专项临时目录已清理。
